How It Works

A direct path from input to prediction.

Responsible Use

Clear limits are part of the interface.

  • The result is not a medical diagnosis.
  • Submitted values are not stored in a database.
  • The model supports only the displayed ranges and categories.
  • Predictions can be incorrect and should be interpreted carefully.
