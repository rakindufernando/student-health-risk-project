System Overview

About the Student Health Risk Predictor

This Flask application uses a saved XGBoost pipeline to classify a student record as Fit, At-risk, or Unhealthy. It provides model-based predictions from the supported health and lifestyle inputs.

Selected Model

{{ model_metadata.get("model_name", "XGBoost") }}

Seven models were compared, including classical machine learning, ensemble methods, and an artificial neural network.

XGBoost was selected because it achieved the highest validation balanced accuracy in the recorded comparison. Balanced accuracy was used because the target classes are imbalanced.

Random Forest and ANN also produced competitive macro F1 scores, so the selection is based on the chosen primary metric rather than a claim that XGBoost is always the best model.

Reliability Features

Software Improvements

Server-side Validation

Every numerical value is checked for type, finite value, and supported range. Every category is checked against the values used during training.

Schema Checking

The input DataFrame uses the same thirteen feature names and order expected by the trained pipeline.

Probability Transparency

The result page shows probabilities for all classes and clearly states that model probability is not medical certainty.

Error Handling

User-friendly messages are displayed while technical details are recorded only in the application log.

Automated Tests

Prediction, validation, route, and error cases can be checked with pytest.

Reproducible Setup

Requirements, run commands, model metadata, and test commands are provided with the project.

Privacy and Limitations

Responsible Use

  • The result is not a medical diagnosis.
  • The application does not save submitted values in a database.
  • The model supports only the displayed ranges and categories.
  • The model can make incorrect predictions.
  • The training data may not represent every student population.
  • The result must not be used for automatic medical decisions.
